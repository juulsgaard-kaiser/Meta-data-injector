# Contributing

Fork the repository and create a feature branch, or use a feature branch here if
you already have write access. Open a pull request targeting `main`.

Explain the problem, the change and relevant validation. Include regression tests
for media correctness and transaction behavior. Never commit credentials or private
media. See [SECURITY.md](SECURITY.md) for private vulnerability reports.

The maintainer, `@xcifer`, reviews changes before merging. Required checks and review
conversations must be resolved. New commits dismiss earlier approvals, so allow
another review after updating the branch. External contributors' workflow runs also
require maintainer approval.

Use the installation and test instructions in [README.md](README.md). Keep changes
focused and preserve unrelated metadata. Do not loosen integrity checks to make a
failing media edit pass.
